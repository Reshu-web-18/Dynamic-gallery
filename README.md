# 🌄 Dynamic Nature Gallery

A simple and responsive Dynamic Image Gallery created using HTML and CSS. This project displays nature-themed images in a four-column gallery layout, providing a clean and attractive way to showcase multiple images.

## 📌 Features

- Four-Column Image Gallery
- Nature-Themed Images
- Clean and Responsive Layout
- Organized Image Display
- Beginner-Friendly Design

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📂 Project Structure

```
Dynamic-Nature-Gallery/
│── index.html
│── c-1.png
│── c-2.png
│── c-6.png
│── c-8.png
│── README.md
```

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Make sure all image files are in the same folder as `index.html`.
4. Open `index.html` in any web browser.

## 📚 Concepts Used

- HTML Image Tag (`<img>`)
- CSS Flexbox
- Image Gallery Layout
- Responsive Design
- Basic CSS Styling

## 📸 Output

The webpage displays:
- A four-column image gallery
- Nature-themed images arranged in an organized layout
- Clean and responsive gallery design
